# Data Model: Aurora Main Screen

All types live in the portable `AuroraCore` package unless noted. All are value types, `Sendable`,
and `Codable` where they are cached. Coordinates are WGS84 degrees; times are UTC `Date`s.

## Bundled reference data

### Station

| Field | Type | Notes |
|---|---|---|
| id | String | FMI code, e.g. `HAN` |
| name | String | As published by FMI, e.g. "Hankasalmi" (not translated) |
| latitude, longitude | Double | From FMI open data |
| yellowThreshold | Double | R for "possible" |
| redThreshold | Double | R for "probable"; must be > yellowThreshold |

10 stations, listed in [research.md R3](research.md). Bundled as `stations.json`.

### Municipality

| Field | Type | Notes |
|---|---|---|
| code | String | Statistics Finland code, e.g. `091` (unique) |
| nameFi | String | e.g. "Helsinki" |
| nameSv | String? | e.g. "Helsingfors"; nil when there is no Swedish name |
| representativePoint | (lat, lon) | Precomputed point inside the polygon |
| boundingBox | (minLat, minLon, maxLat, maxLon) | For fast rejection |
| polygons | [[(lat, lon)]] | Outer rings (multi-part allowed), 4-decimal precision |

308 municipalities (2026). Bundled as a compact file generated by `tools/build-municipalities`.
Display name: Swedish name when the app language is Swedish and `nameSv` exists, otherwise
Finnish.

## Derived values

### StationReading

| Field | Type | Notes |
|---|---|---|
| station | Station | |
| r | Double? | nil when the window is invalid (> 3 missing samples) |
| measuredAt | Date | End of the R window |
| activity | ActivityLevel? | From r and thresholds |

### ActivityLevel — `unlikely | possible | probable`

### Darkness — `tooLight | twilight | dark` (from sun elevation, research R6)

### CloudCondition — `clear | partly | overcast | unknown`, plus optional `octas`, source position and distance

### ChanceLevel — `none | low | moderate | high` (ordered)

### LimitingFactor — `light | twilight | clouds | activity` (optional)

### Chance

| Field | Type | Notes |
|---|---|---|
| level | ChanceLevel | |

| cloudsIncluded | Bool | false when clouds are unknown |

## Rules and validation

- Station selection: nearest station with valid R by great-circle distance. Hysteresis: keep the
  previously used station unless another valid station is at least 5 km closer (no flip-flopping).
- Cloud station: nearest observation with valid octas within 100 km; else `unknown`.
- R window: 61 samples (60 differences) ending at the latest sample time common to X, Y, Z; at most
  3 missing samples; result clamped to ≥ 0.
- Coverage: point-in-polygon on municipalities, else nearest municipality boundary within 15 km,
  else outside coverage.
- Thresholds: `0 < yellow < red`; validated when bundled data is loaded (tests fail otherwise).
